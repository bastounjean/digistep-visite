# DIGISTEP – visite 3D

Site de présentation de la cabine DIGISTEP (Plateau Projet 2026–2027, Grenoble INP – Génie industriel).

En faisant défiler la page, la caméra suit un trajet rendu dans Blender (Cycles, 240 images) : de l'entrée du magasin jusqu'au step motorisé, qui monte de 10 à 35 cm.

- `index.html` : la page
- `frames/` : les 240 images rendues
- `assets/` : logo CardioTest
